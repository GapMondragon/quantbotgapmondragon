# quantbotgapmondragon

High-performance, modernized web platform for **Quantbot Technologies, LP**.

Recreated with mathematical rigor, responsive glassmorphism UI, interactive quantitative market node canvas, and zero runtime dependencies.

## Live Deployments
- **Custom Domain (Cloudflare)**: [quantbot.gapmondragon.dev](https://quantbot.gapmondragon.dev)
- **Netlify Site**: [quantbotgapmondragon.netlify.app](https://quantbotgapmondragon.netlify.app)

## Tech Stack
- **Architecture**: Vanilla HTML5 / CSS3 / ES6 Modular
- **Visuals**: Quantitative Node & Particle Canvas Engine (`js/canvas-bg.js`)
- **Components**: Modals, multi-manager tabs, live filters, mobile drawer (`js/components.js`)
- **Hosting**: Netlify + Cloudflare DNS / SSL

## Local Development
Open `index.html` directly in any browser, or run:
```bash
python3 -m http.server 8080
```
